
**Budgetari** is a feature-rich, secure personal budgeting and expense-tracking Android application built using Java and Android SDK. It helps users manage their daily finances by providing real-time expense tracking, category-based analytics, and secure cloud synchronization.

## ✨ Features

* **Secure Authentication:** Implemented Firebase Authentication supporting secure account access, including phone/OTP-based authentication.
* **Cloud Data Storage:** Integrated Firebase Realtime Database and Firestore for seamless storage, synchronization, and retrieval of user and financial data.
* **Dynamic Analytics & Visualizations:** Integrated **AnyChart-Android** to provide interactive visual representations of spending habits.
* **Comprehensive Expense Tracking:** 
  * Daily, weekly, and monthly spending views.
  * Category-based expense tracking and detailed analytics.
  * Robust transaction history and expense-management workflows powered by Android Activities, custom adapters, and Firebase database operations.
* **Advanced Date Handling:** Utilizes **Joda-Time** for precise, date-based application functionality and period filtering.

---

## 🛠️ Tech Stack & Architecture

* **Language:** Java
* **Platform:** Android SDK
* **Backend & Database:** Firebase Authentication, Firebase Realtime Database, Cloud Firestore
* **Libraries & Tools:** 
  * AnyChart-Android (Data Visualization)
  * Joda-Time (Date Management)
* **Core Concepts:** Object-Oriented Programming (OOP), Event-Driven Architecture, Data Persistence, UI Development, and Debugging.
